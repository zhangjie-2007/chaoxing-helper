学习通助手 · 设置

答对弹题靠大模型或你自己的题库，两者至少要配一个。

答题来源：大模型

兼容 OpenAI 接口格式。默认 DeepSeek，也可以换成任何 OpenAI 兼容网关。

答题来源：本地题库

题库先于大模型匹配，命中就不调用接口（省钱更快）。支持模糊匹配，题目差几个字也能认出来。

三种写法都认：
1. 题目 => A（多选写 ABC 或 A,C）
2. 题目 | 正确选项原文
3. JSON 数组：[{"q":"题目","a":"A"}]，a 也可以是 [0,2]

行为微调

默认值一般就够用，出现异常再动。

跳转等待不要低于 2000ms：站点要把本节观看进度上报完再跳，太快容易被判异常。

认不出题目时用这里

如果弹题出来了但插件没反应，把题目容器的 CSS 选择器加进来。F12 右键题目 → 检查 → 找到外层带题干的 div → 复制它的 class。

点插件里的「识别当前题目」会把诊断结果写进运行日志（页面上有多少个单/多选框、容器 class 是什么），把日志发我就能针对性加规则。

怎么装的

  1. 打开 edge://extensions，右上角打开「开发人员模式」。
  2. 点「加载解压缩的扩展」，选择 D:\大肥鱼工作点\chaoxing-helper 这个文件夹。
  3. 回到学习通课程页，刷新一次页面，插件就会挂上去。
  4. 改完本页设置后点保存，课程页再刷新一次即生效。
